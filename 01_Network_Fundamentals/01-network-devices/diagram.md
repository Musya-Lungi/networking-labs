## 🔍 Explanation

- **Laptop** connects wirelessly via the Access Point  
- **Access Point** bridges wireless traffic to the wired network  
- **Switch** forwards frames within the LAN using MAC addresses  
- **Router** routes packets between networks using IP addresses  
- **Modem** converts signals for ISP communication  
- **ISP/Internet** delivers external services (e.g., YouTube)

---

## 💡 Key Insight

> Data moves step-by-step through specialized devices, each performing a specific role in the communication process.
