# Domain 2 - Network Access
This section covers CCNA Domain 2 topics related to switched networks and wireless access.

## Labs
### 02. 802.1Q Trunking, Native VLAN & Inter-Switch VLANs
- Configure trunk links between switches using 802.1Q encapsulation
- Set and verify Native VLAN on both ends of a trunk
- Restrict allowed VLANs on a trunk link
- Disable DTP with nonegotiate to prevent VLAN hopping attacks
- Verify trunk configuration using show commands
- Troubleshoot Native VLAN mismatch
