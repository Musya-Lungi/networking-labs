# Wireless Concepts

## WLAN

A WLAN allows devices to communicate using radio frequencies instead of Ethernet cabling.

Wireless communication commonly operates on:

* 2.4 GHz
* 5 GHz
* 6 GHz

---

## SSID

The SSID (Service Set Identifier) is the visible wireless network name broadcasted by an access point.

Example:

```text
CorpWiFi
```

---

## WPA2-PSK

WPA2-PSK uses a shared password to authenticate wireless users.

Features:

* AES encryption
* CCMP protocol
* Secure wireless communication
* Widely used in enterprise branch deployments

---

## WPA3 and SAE

WPA3 improves wireless security by introducing SAE (Simultaneous Authentication of Equals).

Advantages over WPA2:

* Better resistance to password attacks
* Improved authentication security
* Stronger key exchange process

---

## QoS in Wireless Networks

Quality of Service (QoS) prioritizes critical traffic such as:

* Voice
* Video conferencing
* Real-time applications

QoS helps reduce latency and improve application performance in congested wireless environments.

---

# BSS vs ESS

| Concept | Description                                  |
| ------- | -------------------------------------------- |
| BSS     | Single access point and connected clients    |
| ESS     | Multiple access points sharing the same SSID |

ESS deployments enable wireless roaming across larger coverage areas.

---

# Wireless Client Connectivity Process

Wireless clients connect using the following sequence:

1. Scanning
2. Authentication
3. Association
4. WPA2 4-Way Handshake
5. Secure Data Transfer
