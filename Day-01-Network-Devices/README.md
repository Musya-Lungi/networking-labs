## 📅 Date
April 2026

---

## 🎯 Objective
Understand core network devices and how they interact to move data across a network.

---

## 🧠 Devices Covered

### 1. Hub
- Broadcasts data to all ports
- No intelligence
- Obsolete due to inefficiency and security risks

### 2. Switch
- Forwards data using MAC addresses
- Operates within a Local Area Network (LAN)
- Reduces unnecessary traffic by sending data only to the intended device

### 3. Router
- Connects different networks
- Uses IP addresses to route traffic
- Acts as the default gateway to external networks (e.g., the Internet)

### 4. Modem
- Converts digital signals to ISP transmission format and vice versa
- Connects the local network to the Internet Service Provider (ISP)

### 5. Access Point (AP)
- Provides wireless connectivity
- Bridges wireless devices to the wired network

### 6. Firewall
- Controls incoming and outgoing traffic based on rules
- Enhances network security

---

## 🌐 Network Flow Overview

A typical data path from a user device to the internet:

Laptop → Access Point → Switch → Router → Modem → Internet

The return traffic follows the same path in reverse.

---

## 💡 Key Concepts Learned

- Switches operate within a LAN using MAC addresses
- Routers connect different networks using IP addresses
- Devices in the same network communicate via switches
- Devices in different networks require a router (default gateway)
- Each device has a specific role in the data transmission process
